# 서버 데이터셋 수집

교란 크기 찾기와 데이터 수집은 서버 OASYS에서 한다. 노트북보다 여러 배 빠르고, 노트북을 꺼도 서버에서 끝까지 돈다. 다 모이면 노트북의 `data/libero_spatial/`로 가져온다.

## 서버

| 항목 | 값 |
|---|---|
| 접속 | `ssh OASYS` |
| GPU | RTX 4090 2, 3번 사용 |
| 동시 실행 | GPU당 3개, 총 6개 |
| 작업 폴더 | `~/wac_cosmos/` |
| Python 환경 | `~/wac_cosmos/cosmos-policy/.venv` (노트북과 같은 공식 `uv sync`) |
| 체크포인트 | `~/.cache/huggingface/hub/` (서버에 있던 캐시) |
| 수집 데이터 | `~/wac_cosmos/repo/data/libero_spatial/` |

## 순서

`wac/server_pipeline.py` 하나가 아래를 차례로 한다.

1. 물체 이동(±8, 9, 10, 11, 12cm)과 카메라 회전(45, 60, 75, 90도)을 동시에 잰다. 크기마다 20번(지시문 10개 × 초기 상태 0, 1번), 교란 seed 9000.
2. 성공률이 40~60%인 크기 중 50%에 가장 가까운 값을 고른다. 3인칭 회전의 범위와 간격을 조정한 뒤 가장 가까운 각도를 초기 상태 5~9번에서 50회 확인한다. 필요하면 3인칭 카메라 위치 이동과 손목 카메라 회전을 순서대로 시험한다.
3. 본수집에 쓰지 않는 초기 상태 30~34번과 35~39번에서 조건마다 50회씩 두 번 잰다. 시드는 19001과 19002를 쓴다. 두 묶음 모두 성공률이 40~60%이면 크기를 확정한다.
4. 정한 크기로 두 조건 500 에피소드를 동시에 수집한다. 묶음과 초기 상태는 `Experiment.md`에 적었다.
5. 묶음별 `result.md`, 전체 `index.csv`와 `README.md`를 만든다. 에피소드 500개와 MP4, NPZ, HDF5 파일을 확인하면 상태를 `finished`로 바꾼다.
6. `server_upload.sh`가 [Hugging Face 데이터셋](https://huggingface.co/datasets/MINSUAI/cosmos-wac-libero-spatial)에 올린다.

물체 크기는 노트북에서 ±8cm 65%, ±12cm 25%가 나왔지만 서버에서 다시 잰다. 같은 조건의 크기 측정과 수집은 같은 기계에서 해야 GPU 차이가 결과에 섞이지 않는다.

## 명령

서버에서:

```bash
cd ~/wac_cosmos/repo
nohup setsid bash -c '
  ~/wac_cosmos/cosmos-policy/.venv/bin/python wac/server_pipeline.py --gpus 2,3 --per_gpu 3 \
    >> ~/wac_cosmos/pipeline.log 2>&1 &&
  bash wac/server_upload.sh > ~/wac_cosmos/upload.log 2>&1
' > ~/wac_cosmos/resume.log 2>&1 < /dev/null &
```

진행 확인:

```bash
ssh OASYS 'cat ~/wac_cosmos/status.json; tail -5 ~/wac_cosmos/pipeline.log'
ssh OASYS 'tail -5 ~/wac_cosmos/upload.log'
ssh OASYS 'nvidia-smi --query-gpu=index,memory.used,utilization.gpu --format=csv'
```

`status.json`에 지금 단계(`size_search_round0`, `collect`, `finished` 등), 잰 크기별 성공 수, 정한 크기가 있다.

## 실시간 감시

서버의 시뮬레이터 화면을 노트북 브라우저에서 한 페이지로 본다. 0.5초마다 갱신되고, 칸마다 왼쪽이 3인칭, 오른쪽이 손목 카메라다.

노트북 PowerShell에서:

```powershell
Start-Process ssh -ArgumentList "-N -L 18765:localhost:18765 OASYS" -WindowStyle Hidden
Start-Process "http://localhost:18765"
```

서버 쪽 화면 서버(`wac/live_server.py`)는 서버 안에서만(127.0.0.1) 열려 있어서 SSH 터널로만 볼 수 있다. 서버의 8765번 포트는 다른 프로그램이 쓰고 있어 18765번을 쓴다.

## 파인튜닝 준비

공식 [LIBERO-Spatial 시연](https://huggingface.co/datasets/nvidia/LIBERO-Cosmos-Policy/tree/b463cbd/success_only/libero_spatial_regen)과 정규화 통계는 서버의 `data/finetune/base/success_only/`에 둔다.

```bash
cd ~/wac_cosmos/repo
DRY=1 bash wac/finetune.sh wac_v1 3
```

이 명령은 공개 체크포인트를 DCP 형식으로 준비하고, `index.csv`에서 train 에피소드 100개를 골라 `data/finetune/train_rollouts/`에 연결한다. 공식 데이터 로더에서 시연, 성공 rollout, 실패 rollout을 각각 읽고, 실행 설정을 `data/finetune/wac_v1/raw/` 아래에 저장한다.

학습을 시작할 때는 사용할 GPU를 지정한다. 기본 설정은 GPU 2장, 유효 배치 32, 시연 샘플 비율 25%다.

```bash
CUDA_VISIBLE_DEVICES=2,3 bash wac/finetune.sh wac_v1 3
```
